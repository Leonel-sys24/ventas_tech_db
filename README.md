# Base de Datos - Ventas Tech (TechStore)

## Descripción del Proyecto
Modelo relacional diseñado para la cadena de tiendas de tecnología **TechStore**, estructurado bajo normas de normalización (3NF) para soportar operaciones de ventas, control de stock y gestión de clientes.

## Estructura de Archivos
- `ventas_tech_db.sql`: Script principal que incluye la limpieza, creación de tablas, inserción de datos iniciales y consultas de validación.

## Guía de Ejecución
1. Conectarse a tu gestor de base de datos.
2. Ejecutar el script completo `ventas_tech_db.sql` en orden secuencial.
3. Verificar la correcta inserción mediante las consultas de validación al final del script.
